# stlkm-catalog

Le répertoire des applications STLKM.

Le fichier [`catalog.toml`](catalog.toml) est lu par le hub STLKM : il y trouve
la liste des applications, où les télécharger et comment les lancer. Les
binaires ne sont pas ici — ils restent dans les *releases* de chaque projet.

Ce dépôt ne contient rien d'exécutable.
